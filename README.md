# 单词小怪兽 🐣

四年级上册英语背单词应用（单文件，纯前端，免登录单机使用）。

## 功能

- 📖 看卡片学单词（音节拆分 + 音标 + 词性 + 中文释义）
- 🌱 背新词（每天 5 个，拼写闯关）
- 🔁 复习旧词（间隔重复记忆）
- ⚔️ 选择大测验、🔤 字母拼写闯关、👂 听音猜词
- 💥 错词本
- 📝 词库管理（导入/导出/备份）

## 使用方式

直接用浏览器打开 `index.html`，或部署到任意静态托管（GitHub Pages / Vercel 等）。

数据存浏览器本地 localStorage（单机使用，换设备/清缓存会丢失进度，可通过「备份/搬家」功能导出导入）。

## 词库数据

词库内置四年级上册 Unit 1-6 共 109 词，数据表在 `index.html` 内：

| 数据表 | 作用 |
|---|---|
| `BOOK_UNITS` | 单词 + 中文（按单元分组） |
| `POS` | 词性 |
| `SYLL` | 音节拆分 + 音标 |
| `EMOJI` | 配图（当前用 emoji，可替换为图片） |
